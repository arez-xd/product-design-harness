# Example requests

## A new screen or feature

```text
/product-design Design the invoices list for accountants who go through hundreds of invoices a day.
```

```text
/product-design A booking app for small yoga studios: the class schedule and sign-up. Use Mobbin for references.
```

```text
/product-design The onboarding for a team plan: invite people, set roles, pick a plan. Build on Opus, decide yourself and show me at the end.
```

## From Figma

```text
/product-design https://www.figma.com/design/… Build this frame in our app, with every state.
```

## A small change

```text
/product-design quick The empty state of the projects list needs a way to import from CSV.
```

## Only part of the path

```text
/product-design frame A settings page for notification preferences.
```

```text
/product-design feedback Crit notes from today: the totals row is lost under the fold; "Archive" reads as delete.
```
